## Decisions

- One email/password Auth user may hold one Staff and one Admin row; the role chosen at login selects the row. Customer remains LINE-only.
- Initial Admin passwords need 12–128 characters, like the bootstrap script. Existing Auth users are found by email via the Admin user list before any create, so their password is never sent to `createUser`.
- Any pending Admin, including the bootstrap Admin, must accept explicitly; disabled Admins get a separate 403 message.
- `requireAdmin` still checks role and active status; the identity check constraint guarantees an active Admin has a bound LINE subject, so no extra check was added (it would also have broken existing Booking/Package fixtures outside this ticket).
- `scripts/bootstrap-admin.ts` is unchanged; it still refuses an existing email or an existing Admin.
