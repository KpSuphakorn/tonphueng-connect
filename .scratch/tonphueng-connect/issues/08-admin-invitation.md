# 08: เพิ่ม Admin และผูก LINE ของผู้รับสิทธิ์

**What to build:** Admin ที่มีสิทธิ์เพิ่มบัญชีผู้ดูแลใหม่ ผู้รับเข้าสู่ระบบ ยืนยันรับสิทธิ์ และผูกตัวตน LINE ของตนก่อนใช้สิทธิ์ Admin ได้

**Blocked by:** 01: เข้าสู่ระบบและตรวจสิทธิ์แต่ละบทบาท.

**Status:** ready-for-agent

**Spec:** [Approved spec](../spec.md)

**Coverage:** User Stories 38-39; ส่วนเพิ่ม Admin ของ AC04 และขอบเขตสิทธิ์ของ AC14

## Acceptance criteria

- [ ] Admin ที่ผ่านอีเมล/รหัสผ่านและ LINE ตามกติกาแล้วเท่านั้นที่เพิ่มบัญชี Admin ใหม่ด้วยอีเมล/รหัสผ่านเริ่มต้นตามสเปกได้
- [ ] ผู้รับเข้าสู่ระบบและยืนยันรับสิทธิ์ พร้อมผูก LINE ที่ server ตรวจยืนยันแล้วกับบัญชีของตน
- [ ] บัญชีที่ยังไม่ยืนยันหรือยังไม่ผูก LINE ใช้สิทธิ์ Admin ไม่ได้ แม้เรียกการทำงานของ Admin โดยตรง
- [ ] หลังผูกแล้ว การเข้า Admin ต้องตรวจบัญชีและตัวตน LINE ให้ตรงตามกติกาเดิม ไม่เก็บ token ที่หมดอายุแทนตัวตนถาวร
- [ ] Customer/Staff ไม่สามารถเพิ่ม Admin หรือกำหนดสิทธิ์ให้ตนเอง และไม่มีการเผยรหัสผ่านหรือ service credentials ในผลตอบกลับ/รายงาน
- [ ] ผ่านการทดสอบ Admin เดิมเพิ่ม -> ผู้รับยืนยัน/ผูก -> เข้าใช้ รวมสิทธิ์ไม่พอ LINE ไม่ตรง และขั้นตอนยังไม่ครบ

## External prerequisites and evidence

- Live acceptance ใช้บัญชีทดสอบที่ผู้ใช้ควบคุมและอนุญาตให้สร้าง ไม่เพิ่มบัญชีจริงในระบบภายนอกโดยอาศัยเพียงการอนุมัติ tickets
